# Plateforme étudiante SCITI

PWA de consultation des résultats, suivi des absences et diffusion
des informations. Projet de l'Akowé groupe.

## Stack
React + Vite + Tailwind (client/) · Node.js + Express (server/) · PostgreSQL

## Équipe
T (coordination) · G (design) · B (front) · A (back) · C (sécurité)

## Démarrage
(à compléter par B et A : installation, variables d'environnement)

## Règles de travail
- Jamais de travail directement sur `main`
- Une branche par tâche, nommée `type/ID-description` (ex. `feat/A-4-migrations`)
- Relecture par un autre membre avant fusion
- Aucun mot de passe ni clé secrète dans le dépôt (.env ignoré)
- Une tâche est terminée quand elle est codée, testée, relue et documentée
